# Олеся Стриха — психолог

Сайт-визитка: онлайн-консультации для взрослых в гештальт-подходе.

Это собранная версия сайта: `index.html` — одна страница со встроенными
стилями, скриптом, шрифтами и изображениями. Файлы в этом репозитории
не редактируются вручную — они целиком заменяются новой сборкой.

Шрифты Literata и Golos Text распространяются по лицензии SIL Open Font
License 1.1 (тексты лицензий — в папке `LICENSES`). Иконки — Lucide
(ISC License) и Simple Icons (CC0).
